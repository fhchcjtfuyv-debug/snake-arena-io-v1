# Slither Drift

A browser-based snake arena game built with Phaser 3 and TypeScript.

## Features
- Offline single-player snake arena with AI bots
- Responsive menu, HUD, game-over screens
- LocalStorage save for best score, settings, player name, skins
- PWA manifest + service worker for install/offline use
- Vite + TypeScript build pipeline

## Requirements
- Node.js 18+
- npm 9+

## Install
```bash
npm install
```

## Run in development
```bash
npm run dev
```

## Build for production
```bash
npm run build
```

## Preview production build
```bash
npm run preview
```

## Notes
- This project is designed for the browser and works in offline mode without a backend service.
- The gameplay is inspired by arena snake games but uses original assets and custom visuals.
